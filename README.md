# Simon Game

A simple Simon Game built using HTML, CSS, and JavaScript (jQuery). This game tests the player's memory by generating a sequence of colors that the player must repeat correctly.

## How to Play
1. Press any key to start the game.
2. A random color will flash, indicating the sequence.
3. Click the buttons in the same order as the sequence.
4. The sequence gets longer with each correct round.
5. If you make a mistake, the game resets and displays "Game Over."

## Features
1. Dynamic sequence generation.
2. Button animations and sound effects.
3. Level progression.
4. Game restart on failure.

## Technologies Used
1. HTML: Structure of the game.
2. CSS: Styling and animations.
3. JavaScript (jQuery): Game logic and interactivity.

## Setup & Usage
1. Clone this repository
2. Navigate to the project folder
3. Open `index.html` in your browser.
